# LBS-TT Controller

Мобильное приложение для двунаправленной Bluetooth-коммуникации 
с БПЛА LBS-TT на базе broadcast-трансляции телеметрии.

## Возможности

- Установление SPP-соединения с БПЛА (HC-05/06, SpeedyBee BT)
- Передача команд управления (джойстики, режимы полёта) — 20 Гц
- Приём телеметрии (высота, скорость, координаты, батарея) — 10 Гц
- Broadcast-трансляция телеметрии по UDP (порт 8888)
- Отображение состояния БПЛА в реальном времени

## Требования

- Android Studio Hedgehog (2023.1.1) или новее
- JDK 11+
- Android SDK 26+ (Android 8.0 Oreo)
- Телефон с Bluetooth Classic
- Bluetooth-модуль на БПЛА (сопряжён заранее)
